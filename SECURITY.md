# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report them privately via
[GitHub private vulnerability reporting](https://github.com/wandelbotsgmbh/nova-agent-kit/security/advisories/new).
We will acknowledge your report and keep you updated on the fix.

Vulnerabilities in the `nova` CLI itself belong to the
[nova-cli repository](https://github.com/wandelbotsgmbh/nova-cli/security/advisories/new).

## Supported versions

Only the [latest release](https://github.com/wandelbotsgmbh/nova-agent-kit/releases/latest)
(the `release` branch) receives security fixes.
